XBOX Cars ~ VC ~ v0.91 ~ By yojo2 & ALMOST610

Just run gta mod installer and it should lead you through the update (just select the locations as asked)

NOTE: Please use a Clean Install of Vice City

NOTE: At the main screen select the choice (3) the one between # #

  o Install a Custom Vehicle into Vice City

  o Install a Custom Vehicle into GTA3

# o Install a Mod (with a script file) to GTA3 or Vice City #

  o Restore a backup for GTA3 or Vice City (uninstall a mod\vehicle)
