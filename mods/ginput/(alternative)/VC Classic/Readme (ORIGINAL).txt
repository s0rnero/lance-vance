GInput for GTA VC
Alternate button textures - Classic VC buttons


INSTALLATION

	These button textures are a replacement to original GInputVC buttons. This set replaces stock GInput buttons with
	original PS2 and XBOX button textures from GTA VC.

	GInput can be downloaded here:
	http://www.gtagarage.com/mods/show.php?id=24272

	To install those buttons, just put 'models' directory from this archive to your game directory,
	overwriting old files.
