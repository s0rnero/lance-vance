=======   MixMods.com.br   ======= - Best visualization with monospaced fonts, like "Consolas".


------- Instructions:

Extract the folder "GInput" to your Modloader folder.

 - Folder "(alternative)": there are different button styles. If you prefer, replace the "models" folder in the mod's "GInput" folder.
 - Folder "(docs, api)": there is a list of commands, cheats, and tools for modders. You can just ignore it.

-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html


 The mod is now ready for use.
 If your gamepad is pirated, download the "x360ce.zip", extract it to your game folder and start x360ce.exe:
 https://github.com/x360ce/x360ce/releases/latest

 You have several configuration options in the "GInputVC.ini" file.
 For example, if you want to change the buttons from Xbox to PlayStation, enable "PlayStationButtons=1".
 There is sensibility options there too.
 More infos in the file "(docs, api)/Readme (ORIGINAL).txt".
