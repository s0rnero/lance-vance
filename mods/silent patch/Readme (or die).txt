=======   MixMods.com.br   ======= - Best visualization with monospaced fonts, like "Consolas".


------- Instructions:

Extract the folder "SilentPatch" to your Modloader folder. Or if you prefer, to your GTA VC folder, or "scripts" folder.

Replaces the file ddraw.dll on your game folder.

"Data" folder fixes map files, optional but recommended, you can simply replace on the game folder (recommended) or add to modloader.

Note: This mod is already included in Essentials Pack: https://www.mixmods.com.br/2020/12/iii-essentials-pack/
      In this case is on folder "_ESSENTIALS".

-- Download of ASI Loader: MixMods.com.br/2015/08/jogos-em-geral-universal-asi-loader.html
-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html


 Full list of functions in english on "Readme (ORIGINAL).txt".
 Read "Readme (ORIGINAL).txt" if you want to install on Steam or RGL (Rockstar Games Launcher) version.
