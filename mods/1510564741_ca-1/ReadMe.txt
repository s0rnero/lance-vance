# Classic AXIS - Version 1.6 - 03/11/2017
#

Only for Grand Theft Auto III and Grand Theft Auto Vice City, PC Versions.

GTA III 1.0 (all versions) 
GTA VC 1.0 (all versions) 

# Description:
Classic AXIS is a modification that try to improve the gameplay experience by adding a "better" camera movement to GTA: III and Vice City.

In order to work, this plugin require GInput and a ASI Loader.

# Features:
Possibility to move the camera.
Possibility to let the player walk in 4 directions.
Possibility to move camera while driving a vehicle.
Possibility to change camera mode.
Added simple aiming instead 1st person view while aiming with some weapons. 

Code entirely written using Plugin SDK. 
Make fun developing your own mod with it. Visit "https://github.com/DK22Pac/plugin-sdk" for more info.

# Installation:
- Step 1: Make sure you are using an Asi Loader.

- Step 2: Move the files "ClassicAXIS.asi" and "ClassicAXIS.ini" from the folder "III" or "VC" into your GTA: "III" or "VC" directory.

- Step 3: ONLY FOR VC. You may want to add the folder "ClassicAXIS". This is an addon and is not required if the option "bForceLegsMovements" is set to 0.
          Move the folder "ClassicAXIS" from the folder "addon" into your "VC" directory.
