## El error mío que hay que corregir

**El `1.12` arregló mal el blip del destino (fila F2).** Puse un valor fijo
`SCREEN_SCALE_X(12.f)` en `Radar.cpp:1670`. El mod **no** pone un número: lo calcula
desde los otros vértices, y lo dice en el comentario (`:1105`, namespace
`LegendBlipFix`):

```cpp
// In this setup, x3 is incorrect - it should have been (X + scaleX(14.0f)) but is (X + scaleX(2.0f)), same as x4
// We can recover the correct dimensions from x1 (bottom center) and x4 (top left):
// x3 = x1 + (x1 - x4)
const float x3 = x1 + (x1 - x4);
```

O sea `x3 = 8 + (8 - 2) = 14`, y **`12.f` está mal**. Peor: el mod reimplementa la
fórmula para que no dependa de una constante escrita a mano. Eso es lo que hay que
portar, no un número.

**`src/core/Radar.cpp` es del agente B.** Este arreglo es mío y es de una línea, así
que lo hago yo, pero **aviso antes en la coordinación** para que B no lo toque a la vez.
